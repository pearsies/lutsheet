# Fonts

lutsheet is set entirely in **Satoshi** (Light 300, Regular 400 for emphasis).

By default it loads Satoshi from Fontshare's CSS API (see `<head>` in `index.html`).
To run fully offline, download Satoshi from https://www.fontshare.com/fonts/satoshi
(free for personal and commercial use under the ITF Free Font License) and drop these
files in this folder — `css/style.css` already points at them:

- `Satoshi-Light.woff2`
- `Satoshi-Regular.woff2`

The font files are not bundled in this repo because Fontshare's licence does not permit redistribution.
